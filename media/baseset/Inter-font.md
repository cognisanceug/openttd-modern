# Inter font

Inter was designed by Rasmus Andersson and is maintained on [Github](https://github.com/rsms/inter).
It is licensed under the SIL Open Font License 1.1, see `Inter-LICENSE.txt`.

The modern window style of OpenTTD Modern uses it as the default font:
`Inter-Medium.ttf` for the small and normal sizes, `Inter-SemiBold.ttf` for the large size.
The monospace font stays OpenTTD-Mono. The included files are the static TTFs of release v4.1.
